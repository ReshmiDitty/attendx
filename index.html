Safe File Storage & Backups

AttendX operates with 100% C standard file operations. Before any record update or deletion, the system automatically writes a timestamped binary copy to /backups.

Data Directory : /data (students.txt, attendance.txt, users.txt, audit_log.txt)
Backup Directory : /backups (*_YYYYMMDD_HHMMSS.bak)
